# Somewhere in mind

A React country autocomplete exercise with keyboard and mouse selection.

## Run

```powershell
npm install
npm run dev
```

Open `http://127.0.0.1:4173`. The `dev` script builds and serves the app because Vite's development server can misread source paths in this exercise folder's `#`-containing name.

Type part of a country name to see matches. Click a suggestion, or use the arrow keys and Enter. Escape closes the list, and the clear button starts a new search.
